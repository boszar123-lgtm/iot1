8

IoT Security

ความปลอดภัยของระบบ IoT

ความปลอดภัยต้องเป็นส่วนหนึ่งของการออกแบบระบบตั้งแต่ต้น
เพื่อป้องกันการเข้าถึง การแก้ไขข้อมูล และการควบคุมอุปกรณ์
โดยไม่ได้รับอนุญาต ทั้งในปัจจุบันและอนาคต
1

การยืนยันตัวตน(Authentication)

  • ✓ยืนยันตัวตนอุปกรณ์และผู้ใช้งาน
  • ✓ใช้รหัสผ่าน คีย์ดิจิทัล หรือใบรับรอง
  • ✓ป้องกันการปลอมแปลงอุปกรณ์
ตัวอย่างใช้ X.509 Certificate เพื่อยืนยันตัวตนอุปกรณ์ก่อนเชื่อมต่อเข้าสู่ระบบ
2

การเข้ารหัสข้อมูล(Encryption)

  • ✓เข้ารหัสข้อมูลทั้งขณะส่งและจัดเก็บ
  • ✓ใช้โปรโตคอลปลอดภัย เช่น TLS/SSL
  • ✓ป้องกันการดักฟังและแก้ไขข้อมูล
ตัวอย่างใช้ MQTT over TLS หรือ HTTPS ในการรับส่งข้อมูล
3

การควบคุมสิทธิ์(Authorization)

  • ✓กำหนดสิทธิ์ตามบทบาท (Role-based)
  • ✓จำกัดการเข้าถึงข้อมูลและอุปกรณ์
  • ✓ตรวจสอบและบันทึกการเข้าถึง
ตัวอย่างใช้ Role-Based Access Control (RBAC) ในระบบ Cloud Platform
4

การอัปเดต Firmware(Secure Update)

  • ✓อัปเดตซอฟต์แวร์เพื่อเพิ่มความปลอดภัย
  • ✓ยืนยันลายเซ็นดิจิทัล (Digital Signature)
  • ✓กันเฟิร์มแวร์ที่ไม่ได้รับอนุญาต
ตัวอย่างใช้ Secure OTA Update พร้อมตรวจสอบความถูกต้อง
5

การป้องกันภัยคุกคาม(Threat Protection)

  • ✓ตรวจจับและป้องกันการบุกรุก
  • ✓ใช้ Firewall / IDS / IPS
  • ✓เฝ้าระวังพฤติกรรมผิดปกติ
ตัวอย่างตรวจจับความผิดปกติจากการเชื่อมต่อและรับส่งข้อมูล

☑  แนวทางปฏิบัติที่ดีที่สุด (Best Practices)

  • ✓ออกแบบระบบให้ปลอดภัยตั้งแต่เริ่มต้น (Security by Design)
  • ✓ใช้มาตรฐานและโปรโตคอลที่ปลอดภัย
  • ✓อัปเดตซอฟต์แวร์และเฟิร์มแวร์สม่ำเสมอ
  • ✓กำหนดนโยบายการเข้าถึงที่ชัดเจน
  • ✓ตรวจสอบและเฝ้าระวังความผิดปกติต่อเนื่อง
  • ✓อบรมผู้ใช้งานให้ตระหนักถึงความปลอดภัย

⚠  ตัวอย่างภัยคุกคามที่พบบ่อย

▣การบุกรุกอุปกรณ์ (Device Takeover)
◖การดักฟังข้อมูล (Eavesdropping)
✎การปลอมแปลงข้อมูล (Data Tampering)
✹การโจมตีแบบ DDoS
●การเข้าถึงโดยไม่ได้รับอนุญาต
